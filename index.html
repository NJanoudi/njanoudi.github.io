Professional Self-Assessment

Quality-first engineering with an automation mindset

Throughout the Computer Science program, I strengthened my ability to analyze software systems, communicate technical decisions, and build solutions that balance functionality, maintainability, security, and user experience. My professional background as a Software QA Engineer shaped how I approached this capstone: I focused on improving reliability, validating user input, reducing defects, and designing features that can be tested and maintained over time.

My long-term goal is to continue growing toward test automation and Software Development Engineer in Test roles. The artifacts in this portfolio demonstrate that direction through full-stack development, Angular design improvements, algorithmic data processing, MongoDB relationship modeling, and secure handling of user workflows. Together, these enhancements show how my QA experience and computer science coursework support a practical, industry-focused path toward advanced quality engineering.

The capstone artifacts that follow fit together as one progressive improvement of the CS-465 Travlr application. The software design enhancement improved structure and route protection, the algorithms and data structures enhancement improved trip browsing through search, sorting, and pagination, and the database enhancement added a persistent reservation system using MongoDB and Mongoose relationships.

Capstone Project

CS-465 Travlr Full-Stack Application

A MEAN stack travel application originally developed in CS-465 and enhanced in CS-499 to demonstrate software design and engineering, algorithms and data structures, and databases.

Project Overview

The Travlr application includes a public travel site, an Angular admin interface, a Node/Express API, and MongoDB data storage. My enhancements improved route protection and validation, added dynamic trip list processing, and introduced a MongoDB-backed reservation system that links authenticated users to trips.
